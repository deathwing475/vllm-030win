**0.29（SystemPanic）不是 0.27.1 的等价物**——它吸收了大量上游演进。以下 overlay 内容**已判定免搬**：

## 5. 归因修正存档（防重蹈）

1. **「Marlin 分叉」撤销**：0.27/0.29 的内核清单顺序与 Marlin 位宽表（uint4b8/uint8b128/fp8/fp4）逐字相同——0.27 生产同样由 Marlin 接 int4 embed/lm_head，**非迁移差异**；「旧栈全线 Humming」是对步骤 010 单条日志的过度概括。
2. **S6 的 eager 21.x vs 43 归因作废**：口径混杂（单发续写 vs runner 3×5 median）+ fp8/nvfp4 KV 读带宽差都可能贡献；批 4/5 后用 runner v2 口径重测再谈。
3. 0.29 的 reasoning 字段名 = `message.reasoning`（非 reasoning_content）；GSQ chat_template 硬编码 "Reasoning effort xhigh" system 提示——thinking 发散/答非所问归模型+模板，非引擎（S2/S14 PPL 已锁前向等价）。
