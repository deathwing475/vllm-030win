## 6 红线速查（一行式；**展开与反例 = 详版「必守」同编号**）

1. **改完生产参数 → grep 全仓旧值**，逐个判定"历史记录 vs 现役描述"（必守 5）。
2. **仓库内文件写入一律走 Write/Edit**，不得 `sed -i`（会把 CRLF 变 LF）；`.cmd` 必须 **CRLF**，`.md`/`.py` 是 LF（必守 4）。
3. **绝不在记录仓目录下起 python**；起服走 `_tmp_line_b\boot_keep.py`（必守 2）。
4. **链式 bash→内联复杂 PowerShell 必崩** ⇒ kill 走文件版 `tools/kill_vllm_orphans.ps1`、起服走 `boot_keep.py`（必守 10）。
5. **任何 venv 源码补丁必须有 revert 脚本且实测可逆**；A/B 阴性即回退（必守 14）。**改被模型/图编译引用的源文件 = 换 AOT 缓存键** ⇒ 首 boot 必重编译且退化，**一律双 boot 或走 watchdog**，禁止拿单次冷 boot 判回归（必守 17；只改 `kvmem_workspace/` 不触发）。
6. **kill 后先等独显回落 <800 MiB（实测 ~124 MiB）再起**（必守 18）；停服按 CommandLine 杀（文件版 `tools/kill_vllm_orphans.ps1`）。
7. **速度断言必须先报页步中位（`capture drain` 相邻差）且 ≥3 boot**；单 boot 只能当"该 boot 的状态"（必守 7，078 升级条款）。分型：`utilization.gpu` 必须配 `utilization.memory` + `power.draw` + `pcie.link.*.current/max` 一起看。
8. **全 CUDA graph 兼容是一等判据**（`--enforce-eager` 慢 4×）；图改动必须过 needle（必守 21、11）。投机下"token 数"不区分 prefill/decode ⇒ 步型必须由连接器显式授权（`capture.arm/disarm`）。
9. **判"某请求有没有走视窗"只认分支指纹** `kvmem_retrieval_*.json` 的 `recent_tokens`：**16,384 = 视窗、32,768 = 原生**；禁止用 TTFT/连贯性/`finish_reason` 反推（必守 16⑦）。**每 boot 换 `VLLM_KVMEM_DUMP` 目录**（`_%03d` 每 boot 从 001 重号 ⇒ 复用即静默覆盖证据），且**探针 `--dump-dir` 必须等于引擎的 `VLLM_KVMEM_DUMP`**（必守 16⑧、20）。
10. **`VLLM_KV_GROUP_SIZE>1` ⇒ "层数"与"组数"是两个维度**：任何逐层/逐槽 KV 写入必须按 `group_ids` 展开 + 打印 `(group, block_id)` 覆盖集合 + 读回校验（`VLLM_KVMEM_BAKE_VERIFY`）（必守 16⑨）。
11. **带投机 ⇒ `mbt ≥ 页长 + num_spec`**（1456 页长 ⇒ 1458），否则首块裁到 0 token **静默死锁**；判"会不会撞"看 prompt 是否长过 `mbt − draft_slots`，**别拿短冒烟当臂通了**（必守 16⑩、22①）。**验证装配/视窗必须先 flush 原生前缀缓存**（不同 nonce 的长请求），装载拷贝必须发在 `start_load_kv`（必守 22②③）。**KVMem 臂的余量判据要换口径**（无 8 GiB mmap，共享基线 4,198 MiB；照抄生产公式会算出 −4,100 的假读数）（必守 19）。
12. **验收零容差 + 阴性如实记录**：判据没达成写 INCOMPLETE，不许用"机制走通"替代判据；PPL 非位精确（正确性主判 = needle 多深度）。**环境契约**：VS vcvars64 + `HOME=C:\fi` + CUDA 8.3 短路径 + LIB + TMP/TEMP→G 盘（勿删 `_tmp_anchors`；`_tmp_prod029` 是生产在用的 8 GiB offload mmap）+ flashinfer 0.6.18 两补丁——抄任一 `tools/serve_gsq_*` launcher（必守 1、12）。
