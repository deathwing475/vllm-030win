3. **绝不在记录仓目录下起 python**；起服走 `_tmp_line_b\boot_keep.py`（**只用于 `.cmd`**，ps1 一律 `powershell -File`，080 踩过静默失败）（必守 2）。
4. **链式 bash→内联复杂 PowerShell 必崩** ⇒ kill 走文件版 `tools/kill_vllm_orphans.ps1`、起服走 `boot_keep.py`（必守 10）。
5. **venv 补丁必须有 revert 脚本且实测可逆**（必守 14）；**改被图编译引用的文件 = 换 AOT 键** ⇒ 一律双 boot 或走 watchdog，禁止单次冷 boot 判回归（必守 17；只改 `kvmem_workspace/` 不触发）。
6. **kill 后先等独显回落 <800 MiB 再起服**（必守 18）。
7. **速度断言必须先报页步中位且 ≥3 boot**；单 boot 只算"该 boot 的状态"（必守 7）。分型必配 `utilization.memory`/`power.draw`/温度/`pcie.link.*`（另见必守 25②）。
8. **全 CUDA graph 兼容是一等判据**（`--enforce-eager` 慢 4×），图改动必须过 needle（必守 21、11）；投机下"token 数"不区分步型 ⇒ 步型必须由连接器显式授权（`capture.arm/disarm`）。
9. **判"有没有走视窗"只认分支指纹** `recent_tokens`：**16,384 = 视窗、32,768 = 原生**（禁 TTFT/连贯性/`finish_reason` 反推）；**每 boot 换 `VLLM_KVMEM_DUMP` 目录**、探针 `--dump-dir` 必须与它相同（必守 16⑦⑧、20）。
10. **`VLLM_KV_GROUP_SIZE>1` ⇒ "层数"≠"组数"**：逐层/逐槽 KV 写入必须按 `group_ids` 展开 + 打印 `(group, block_id)` 覆盖 + 读回校验（必守 16⑨）。
11. **带投机 ⇒ `mbt ≥ 页长 + num_spec`**（1456 ⇒ 1458），否则首块裁到 0 token 静默死锁；判撞看 prompt 是否长过 `mbt − draft_slots`，别拿短冒烟当臂通。**验证装配/视窗必须先 flush 原生前缀缓存**，装载拷贝发在 `start_load_kv`（必守 16⑩、22）。**KVMem 臂余量换口径**（必守 19：080 实测本臂快慢两态共享都是 **8,654-8,666 MiB** ⇒ 那是锁页 + 权威区的正常足迹，**不是"被挤"**）。
12. **验收零容差 + 阴性如实记录**：判据没达成写 INCOMPLETE，不许用"机制走通"替代；PPL 非位精确（主判 = needle 多深度）。**环境契约**：VS vcvars64 + `HOME=C:\fi` + CUDA 8.3 短路径 + LIB + TMP/TEMP→G 盘（勿删 `_tmp_anchors`；`_tmp_prod029` 是生产在用的 8 GiB mmap）+ flashinfer 0.6.18 两补丁——抄任一 `tools/serve_gsq_*` launcher（必守 1、12）。
13. **计时口径四条**（079，全文 = 详版必守 24）：门控日志必须自证在跑；`drain()` 第一次 `.cpu()` 等整条流 ⇒ 不拆 `sync`/`copies` 就会把模型计算记成拷贝；`dt` 含探针间空闲 ⇒ 剔 `dt/步 > 2×` + 分组取中位 + 残差清零才许定罪；**"名次"是三个量**（`rank_by_logit` ≠ `page_scores` ≠ **时间序槽位**，只有最后者决定进槽），页长一变页号必须重算。
14. **归因三条**（080，全文 = 详版必守 25）：①**断言"时间在某处"前先证明那段被计量过**（079 把未计量的 `capture.record` 记进 `outside`，实测慢态 94.62% 栈顶就是那里的 `torch.equal`）；拿不到段就上 **py-spy**（外部只读、零 AOT 风险）。②**host 阻塞在同步调用上的墙钟 ≠ GPU 在算**。③**命中率必须报采样次数**（单次 32-token serve 会把命中读成 miss）。
