## 7 红线速查（一行式；**展开与反例 = 详版「必守」同编号**）

1. **改完生产参数 → grep 全仓旧值**，逐个判定"历史记录 vs 现役描述"（必守 5）。
2. **仓库内文件写入一律走 Write/Edit**，不得 `sed -i`；`.cmd` 必须 **CRLF**，`.md`/`.py` 是 LF（必守 4）。
3. **绝不在记录仓目录下起 python**；起服走 `_tmp_line_b\boot_keep.py`（**只用于 `.cmd`**，ps1 一律 `powershell -File`，080 踩过静默失败）（必守 2）。
4. **链式 bash→内联复杂 PowerShell 必崩** ⇒ kill 走文件版 `tools/kill_vllm_orphans.ps1`、起服走 `boot_keep.py`（必守 10）。
5. **venv 补丁必须有 revert 脚本且实测可逆**（必守 14）；**改被图编译引用的文件 = 换 AOT 键** ⇒ 一律双 boot 或走 watchdog，禁止单次冷 boot 判回归（必守 17；只改 `kvmem_workspace/` 不触发）。
6. **kill 后先等独显回落 <800 MiB 再起服**（必守 18）。
7. **速度断言必须先报页步中位且 ≥3 boot**；单 boot 只算"该 boot 的状态"（必守 7）。分型必配 `utilization.memory`/`power.draw`/温度/`pcie.link.*`（另见必守 25②）。
7.5. **pinned host 大区吃 WDDM 提交预算**（必守 27，083）：boot OOM 先查 pinned 分配横幅（`snapshot region ... GiB host`）与 driver 级报错（无 "Tried to allocate"）；旋钮 `SNAPSHOT_EVERY_PAGES`/`_KEEP`，且 `keep×every ≥ 边界存活期`。
7.6. **投机档 = 容量要重算 + draft 空模块会先打死 boot**（必守 28，085）：换投机档必须按引擎自估的 `estimated maximum model length` 重定 `max-model-len`（混合 GDN 上每 token KV +43%，`gpu-memory-utilization` 救不了 = 它比的是启动空闲）；`method` 字符串会被 alias 成 `mtp`，判据 = 日志里 resolve 出的 draft 类名；EXL3 的 MTP/EAGLE 会死在"draft 载入后才从 target 共享、因此为空"的 `embed_tokens`/`lm_head` 上。
8. **全 CUDA graph 兼容是一等判据**（`--enforce-eager` 慢 4×），图改动必须过 needle（必守 21、11）；投机下"token 数"不区分步型 ⇒ 步型必须由连接器显式授权（`capture.arm/disarm`）。
9. **判"有没有走视窗"只认分支指纹** `recent_tokens`：**16,384 = 视窗、32,768 = 原生**（禁 TTFT/连贯性/`finish_reason` 反推）；**每 boot 换 `VLLM_KVMEM_DUMP` 目录**、探针 `--dump-dir` 必须与它相同（必守 16⑦⑧、20）。
10. **`VLLM_KV_GROUP_SIZE>1` ⇒ "层数"≠"组数"**：逐层/逐槽 KV 写入必须按 `group_ids` 展开 + 打印 `(group, block_id)` 覆盖 + 读回校验（必守 16⑨）。
11. **带投机 ⇒ `mbt ≥ 页长 + num_spec`**（1456 ⇒ 1458），否则首块裁到 0 token 静默死锁；判撞看 prompt 是否长过 `mbt − draft_slots`，别拿短冒烟当臂通。验证装配/视窗必须先 flush 原生前缀缓存，装载拷贝发在 `start_load_kv`（必守 16⑩、22）。KVMem 臂余量换口径 = 必守 19（快慢两态共享记账逐字相同 ⇒ 正常足迹，**不是"被挤"**）。
12. **验收零容差 + 阴性如实记录**：判据没达成写 INCOMPLETE，不许用"机制走通"替代；PPL 非位精确（主判 = needle 多深度）。**环境契约全文 = 交接文档 §2**（勿删 `_tmp_anchors`；`_tmp_prod029` 是生产在用的 8 GiB mmap）——起服一律抄任一 `tools/serve_gsq_*` launcher（必守 1、12）。
13. **计时 / 归因 / 命中率口径**（079+080，**全文 = 详版必守 24、25**）：断言"时间在某处"前先证那段被计量过；host 阻塞墙钟 ≠ GPU 在算；`dt` 含空闲 ⇒ 剔离群 + 分组中位 + 残差清零才许定罪；"名次"是三个量，只有**时间序槽位**决定进槽；命中率必须报采样次数。
14. **kernel 级取证**（081，**全文 = 详版必守 26**）：判"慢在提交还是执行"只认 **device busy 的区间并集**；**"boot 态"不是最小单位**（先在单次前向内部找双峰占比）；名集合不同 ≠ tactic 非确定；否证"他占客户端"须 PDH；视窗探针前不许插会入库的请求。
