## 7 红线速查（一行式；**展开与反例 = 详版「必守」同编号**）

1. **改完生产参数 → grep 全仓旧值**，逐个判定"历史 vs 现役"（必守 5）。
2. **仓库内文件写入一律走 Write/Edit**，不得 `sed -i`；`.cmd` 必须 **CRLF**，`.md`/`.py` 是 LF（必守 4）。
3. **绝不在记录仓目录下起 python**；起服走 `_tmp_line_b\boot_keep.py`（ps1 一律 `powershell -File`，080 踩过静默失败）（必守 2）。
4. **链式 bash→内联复杂 PowerShell 必崩** ⇒ kill 走文件版 `tools/kill_vllm_orphans.ps1`、起服走 `boot_keep.py`（必守 10）。
5. **venv 补丁必须有 revert 脚本且实测可逆**（必守 14）；**改被图编译引用的文件 = 换 AOT 键** ⇒ 双 boot 或 watchdog，禁止单次冷 boot 判回归（必守 17；只改 `kvmem_workspace/` 不触发）。
6. **kill 后先等独显回落 <800 MiB 再起服**（必守 18）。
7. **速度断言必须先报页步中位且 ≥3 boot**；单 boot 只算"该 boot 的状态"（必守 7）。分型必配 `utilization.memory`/`power.draw`/温度/`pcie.link.*`（必守 25②）。
7.5. **pinned host 大区吃 WDDM 提交预算**（必守 27，083）：boot OOM 先查 pinned 分配横幅与 driver 级报错（无 "Tried to allocate"）；旋钮 `SNAPSHOT_EVERY_PAGES`/`_KEEP`，`keep×every ≥ 边界存活期`。
7.6. **投机档 = 容量要重算 + draft 空模块会先打死 boot**（全文 = 必守 28 五条：按引擎自估长度重定 `max-model-len`；`mbt` 抬过页长但不能多抬；`method` 会被 alias；EXL3 的 MTP/EAGLE 死在空 `embed_tokens`/`lm_head`；**验收含 ≳10K 长请求**）。
7.7. **接 DFlash2 到新 target 前先算三个数再写 adapter**（必守 29，087）：`fc` 宽 = `len(target_layer_ids) × target_hidden`（唯一运行期守卫）、`mask_token_id < vocab`、`max(aux) < num_hidden_layers`；**只能走 V2 runner**（V1 静默降级 DFlash1）；装饰品清单 = 29③。
7.9. **写"装不下/容量 NO-GO"之前，先逐条 diff 同卡已跑通的生产 launcher**（必守 32，089）：结论限定范围（"这支臂装不下" ≠ "这张卡装不下"）；说"换硬件/减权重"前先问"有没有已跑通配置可抄"；别把第二探针打进 `--max-num-seqs 1` 的臂（排队把 TTFT 读成慢档）。
7.10. **容量判据出手前先分解 `need(L) = a + b·L`；`GPU KV cache size: N` 是 `max_concurrency × max_model_len` 不是字节** ⇒ 禁止"池字节 ÷ N"；抄来的 flag/env 标 `human-copied` 等派生化（**全文 = 必守 34 + 设计档 §2**）。
7.11. **阴性腿要先证明 boot 走得到目标代码；"逐字节回归"只认 boot 不变量**（同 boot 双路径互比 / 误差 ÷ 量化步长 / 页账 / canary）——原始页字节本就逐 boot 抖（**全文 = 必守 35**）。
7.12. **装配类实验的 native prefix cache 必须确定性清除（必守 36，101）**：探针 flush"覆盖全部池块"前提 = 池 < ingest+flush 之和，命中量逐 boot 漂移 0%↔98.4% 赌不得 ⇒ 探针 `--reset-prefix-cache` + 臂 `VLLM_SERVER_DEV_MODE=1`（`/reset_prefix_cache` = dev 路由，不开必 404）；TTFT 对照须同 boot 同态；装配没触发先读 asm-miss 诊断行。
8. **全 CUDA graph 兼容是一等判据**（`--enforce-eager` 慢 4×），图改动必须过 needle（必守 21、11）；投机下"token 数"不区分步型 ⇒ 步型由连接器显式授权（`capture.arm/disarm`）。
9. **投机/臂口径（全文 = 必守 16/19/20/22）**：**带投机 ⇒ `mbt ≥ 页长 + num_spec`**，否则首块裁 0 token 静默死锁。KVMem 臂口径（必守 19）只在再入该线时才需要。
10. **验收零容差 + 阴性如实记录**：判据没达成写 INCOMPLETE，不许"机制走通"替代；PPL 非位精确（主判 = needle 多深度）。**环境契约 = 交接文档 §2**（勿删 `_tmp_anchors`）——起服一律抄任一 `tools/serve_gsq_*` launcher（必守 1、12）。
11. **计时/归因/命中率口径**（全文 = 必守 24、25）：断言"时间在某处"前先证那段被计量过；host 阻塞墙钟 ≠ GPU 在算；残差清零才许定罪；命中率必须报采样次数。
12. **kernel 级取证**（081，全文 = 必守 26）：判"慢在提交还是执行"只认 **device busy 的区间并集**；**"boot 态"不是最小单位**；否证"他占客户端"须 PDH。
